# Mechatronics Launchpad
This repository is meant to serve as a jumping-off point when doing mechatronics development. The
primary intent is for it to provide good references and documentation for doing ESP32 and Linux
application development. Note that all procedures and scripts were developed for Linux, and may not
(and in many cases _will not_) work in macOS or Windows.

This repository will also host shared C and Python module code that can be referenced by external
repos hosting specific applications.

This README will grow to include a directory as the repo is fleshed out.
